# Hướng dẫn làm việc cho agent

Áp dụng các tài liệu này cho mọi thay đổi mã nguồn trong repository `Web QLCafe`.

Đọc theo thứ tự:

1. [RULES.md](RULES.md) — quy tắc bắt buộc.
2. [CONVENTIONS.md](CONVENTIONS.md) — quy ước dự án.
3. [CONSTRAINTS.md](CONSTRAINTS.md) — các ràng buộc an toàn và phạm vi.
4. [CODEGRAPH.md](CODEGRAPH.md) — quy trình phân tích Codegraph bắt buộc.

Hướng dẫn trong `AGENTS.md` nằm gần tệp đang sửa có độ ưu tiên cao hơn.
